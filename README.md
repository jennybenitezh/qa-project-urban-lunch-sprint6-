## 📌 Descripción del Proyecto

El objetivo de este proyecto es realizar la documentación, diseño de pruebas y ejecución testing móvil para la primera versión de lanzamiento en **Android** de la aplicación **Urban.Lunch**.

Se analizaron los requisitos técnicos y funcionales de la aplicación (enfocándose en los apartados destacados en negrita), diseñando una **lista de comprobación (Checklist)** para validar el flujo de pedido, la selección de restaurantes, los puntos de recogida y el comportamiento de la interfaz de usuario en dispositivos Android.

---

## 🛠️ Herramientas y Entorno de Prueba

* **Android Studio / Emulador Android** (o Dispositivo Físico Android).
* **APK de Urban.Lunch** (Versión de lanzamiento asignada).
* **Jira**: Registro y gestión de informes de errores (Bug Reports) con logs y capturas de pantalla/video del dispositivo.
* **Google Sheets / Docs**: Formato oficial de entrega de listas de comprobación y enlaces a tickets.

---

## 📑 Estructura de la Documentación

| Sección | Tipo de Documento | Descripción / Alcance |
| :--- | :--- | :--- |
| **Lista de Comprobación Móvil** | Checklist | Cobertura de requisitos clave: navegación, pantallas de pedidos, restaurantes, selección de puntos de recogida y respuestas de interfaz. |
| **Pruebas de Interfaz (UI/UX)** | Checklist Móvil | Validación de botones, campos de texto, comportamiento en rotación de pantalla (orientación) y notificaciones/alertas. |
| **Reporte de Errores** | Bug Reports (Jira) | Documentación formal de fallos detectados durante la ejecución de las pruebas en el emulador. |

---

## 📱 Aspectos Probados en la App Móvil

- [x] **Flujo de selección de restaurantes:** Visualización de listas, filtros y detalles.
- [x] **Proceso de pedido (Urban.Lunch):** Selección de platos, adición al carrito y resumen de compra.
- [x] **Puntos de recogida:** Selección de ubicación y confirmación de punto de entrega.
- [x] **Usabilidad y comportamiento Android:** Respuestas al botón "Atrás" nativo de Android, manejo de teclados en pantalla y modales de confirmación.

---

## 🐞 Reportes de Errores (Jira)

Los errores detectados fueron documentados en Jira adjuntando:
1. **Título del Bug** (Específico con componente/pantalla afectada).
2. **Entorno Móvil** (Versión de Android, modelo de dispositivo/emulador y resolución).
3. **Pasos detallados para reproducir**.
4. **Resultado Esperado vs. Resultado Obtenido**.
5. **Adjuntos:** Capturas de pantalla o grabaciones de pantalla del emulador Android.
